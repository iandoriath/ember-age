# Session Log

*One entry per session. Copy the template; the ledger below it is the campaign's memory.*

## Template

```markdown
## Session N — TITLE (date)

**Where:** system / world / beacon
**Obligation triggered:** whose, and how it bit
**Beacons:** relit / attempted / learned of
**Fragments gained:** name — tag (Jedi/Sith/Civic) — bears on Question…
**Factions moved:** who noticed the crew, and what they now want
**Debts & favors:** who owes whom
**XP awarded:**
**The line of the night:**
```
