# Terms of the Era

*The appendix glossary — the words everyone at the table should end up using without thinking.*

| Term | Meaning |
|---|---|
| **AR** | After Ruusan, the common calendar |
| **the Withering** | The long decline |
| **the Ebb / the Awakening** | The Force's fall and return |
| **wayfinder** | Scout-envoy-archaeologist; the party |
| **rutter** | An inherited, annotated route-log |
| **scrip** | Sector currency |
| **first-lighting** | Fee and honor for reopening a beacon |
| **the Lamplighters** | The beacon-tenders' guild: it posts the first-lighting prizes, certifies every relight, and sets the order the beacons come back in. Its head is the **Grandmaster of Charts** |
| **first-lighting certificate** | The guild's paper for a relit beacon. It asks one question — *lighting party?* — and a guild witness of record signs what the answer was. What goes on it stays on the record |
| **the Adjournment** | The Senate's vote of 12 AR suspending the dark sectors' seats, charters and obligations sine die — the Rim was adjourned, not the Republic; the Order withdrew with it |
| **the Temple** | The Jedi Order's one house, on Coruscant — where the gifted are sent, young, and not sent back |
| **the withdrawn** | The Temple's word for the Jedi who refused the recall and stayed in the Rim. They called themselves Jedi |
| **the Naboo Admiralty** | The fleet that refused demobilization, anchored at Naboo beyond the Enarc Run — the last state navy in the galaxy, and now its own state |
| **the Naboo lane** | What the table calls the Enarc Run: the lane from Enarc down toward Naboo and the Admiralty's home waters |
| **the black lanes** | The dark, unregistered routes the Kajidics never stopped flying |
| **kajidic** | A Hutt clan-corporation. Together, the one interstellar institution the Withering made stronger |
| **a posting** | A Guild bounty, the one writ that still travels |
| **the Quiet** | Deep-rim slang for dead space |
| **the Run** | The Duros Space Run — and, in spacer mouths, the whole dark country around it: you live and fly *out on the Run*. The lane itself is being relit hop by hop back toward the Hydian Way |
| **the Grumani sector** | The old principality cluster along the Run's deep half — Sith country in the wars |
| **the Drift** | Okrent's Drift, the port that grew on the footings of Bannistar Station's fuel gantries. Where the crew starts |
| **the Anchorage** | Enarc under Sorulba the Anchor: a closed Hutt kingdom on the Run's first junction. Any ship may dock; none has left in forty years |
| **the Dead Gate** | The Run's mouth at Darkknell, as the living end sees it: the deep beacons were war infrastructure and must be rebuilt, not relit, and no bond-writer on Darkknell will underwrite the attempt |
| **the necrology** | The Vigil's list of the war dead, Jedi and Sith in one column, read aloud at every funeral |
| **grey tape** | The Vigil's seal — grey tape and script across a door, a tomb, a battlefield. Don't touch what they've taped off |
| **fragment** | A tangible piece of the true history: a rutter, a living witness, an archive cell, a droid's memory. Tagged Jedi, Sith, or Civic. See [Lore Fragments](../mechanics/lore-fragments.md) |
| **Reconstruction / Question / Insight** | With enough fragments bearing on one named **Question**, the crew attempts a **Reconstruction** and, if it holds, climbs a rung of the answer and earns an **Insight**. See [Lore Fragments](../mechanics/lore-fragments.md) |
| **slicing** | Computer intrusion, in the era's own word — the only one anyone at the table uses |
