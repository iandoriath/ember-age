# Threads

*The information war, tracked: who knows what, who holds what, who owes whom. The campaign's currency is testimony — this page is the bank ledger. On the GM screen these three tables are live state on the Trackers tab; this file is the seed and the paper fallback.*

One boundary keeps it clean: **objects that are lore fragments live in the [Fragment Tracker](fragment-tracker.md)** (it has its own Holder column). Track everything else here — deeds, debts, promises, biographies sold, and the things factions know that they should not.

## When to write a row

Write a **knows** row the moment information changes hands off-camera or on — a name on a record, a biography sold, a file harvested — because three sessions later "wait, who knows that?" is the question that decides a scene. Write a **holds** row when custody moves. Write a **debts** row for anything owed in either direction, including promises: in this era a kept promise is a reputation and a broken one is a clock.

And remember the ledger cuts both ways: the Weeding reads this page too. A witness who knows too much and filed nothing is not a loose end — it is a target ([Faction Clocks](faction-clocks.md), the Ladder of Sightings).
